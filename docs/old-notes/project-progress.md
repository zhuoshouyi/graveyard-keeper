# 守墓人攻略 — 项目进度

## 已完成

- **4标签页面**：概览（Overview）、合成表（Crafting）、任务（Quests）、NPC商店（NPC Shop）
- **按模块分组**：合成数据按 crafting module 分组展示，NPC数据按 NPC 角色分组展示
- **按解锁排序**：合成配方按 `unlock_order` 排序，阶段解锁内容清晰可见
- **中世纪像素风**：UI 采用中世纪像素风格设计，贴合游戏主题
- **服务注册**：以 `route` 类型注册到服务面板（8899端口的子路由 `/game/graveyard-keeper`）
- **服务面板集成**：在 `KNOWN_SERVICES` 中注册，配置了 `SERVICE_LINKS` 跳转链接
